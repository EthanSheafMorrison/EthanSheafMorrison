/ PROJECT

Kihikihi

Exhibition identity and website for an experimental sound and electronics installation by Anne Niemetz with Newton Chan and Sam Carswell.

/ DATE

2024

/ ROLE

Graphic design, art direction, web design, web build

/ SCOPE

Identity system, print ephemera, gallery signage, catalogue, website

/ OVERVIEW

Kihikihi takes its name from the Māori word for cicada. The identity explores emergence, rhythm, and resonance through repetition, waveform motifs, and modular typography. The system spans risograph ephemera, flexible logos, gallery signage, and a responsive website that documents the work and context.

Objective: build a cohesive language that supports collaboration and experimentation while respecting cultural nuance and place.

/ APPROACH

  • Waveform-inspired rules and grids for motion and flow
